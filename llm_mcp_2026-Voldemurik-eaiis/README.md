# SmartClass — GigaChat + MCP, практика по алгоритмам и прикладному ИИ

В этом шаблоне 24 персональных варианта: **12 Context7** (NumPy, pandas, scikit-learn, Hugging Face/CLIP), **6 Git/GitVerse**, **6 Filesystem**.

**Правило курса:** каждый студент реализует предметную логику **одного собственного MCP-сервера** (три заранее заданных инструмента в персональном `student/own_server.py`) и подключает **один готовый**. GigaChat управляет инструментами в одном цикле **Plan → Build → Review**. 

Начните с [START.md](START.md): **ваш репозиторий → ветка `student/<логин>` → дождаться `SmartClass - Create personal MCP task` → прочитать TASK.md → выполнить работу → добавить ключ GigaChat в Secrets → вручную запустить Checker → Pull Request в master**.

Папки `course/` и `.gitverse/workflows/` — инфраструктура. Пишите код в `student/`, входные данные находятся в `case/`, созданный вариант закреплён в `variant.json`. Эти файлы появятся только в вашей рабочей ветке после успешного Create.

Библиотеки и примеры подключения — в [MCP_GUIDE.md](MCP_GUIDE.md). Состав выходного артефакта, требования и [правила оценивания](COMMON_TASK.md#оценивание--до-5-баллов) — в [COMMON_TASK.md](COMMON_TASK.md).

**Дополнительно студент самостоятельно пишет учёт токенов GigaChat:** запросы и токены по этапам Plan/Build/Review, общий итог, `token_usage.json` и короткая интерпретация расхода. Транспорт только предоставляет исходный `usage`, без готового счётчика.

**Оценивание — до 5 баллов:** не пройден полный ручной Checker — работа возвращается на доработку; пройден — преподаватель проверяет артефакт и выставляет балл по содержанию. Зелёный CI не гарантирует максимальную оценку.
